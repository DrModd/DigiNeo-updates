# DigiNeo-updates

Каталог онлайн-обновлений для сетевого стримера **DigiNeo**. Плата читает `manifest.txt`,
скачивает указанный пакет, проверяет SHA-256 и ставит файлы без перепрошивки
(меню → Усилитель → Обновление).

## Формат
- `manifest.txt` — последняя версия: `version`, `file`, `sha256`, `size`, `notes`.
- `packages/digineo-<версия>.tar.gz` — пакет: `VERSION`, `files/` (дерево относительно `/`), необязательный `post.sh`.
- Разрешены только каталоги `var/www`, `opt`, `etc`, `usr/local`, `lib/systemd/system`.
  Если `post.sh` завершится с ошибкой — файлы автоматически возвращаются.

## Выпуск новой версии
```
mkdir -p src/files/var/www            # положить изменённые файлы по их путям на плате
bash tools/make-package.sh 1.0.2 src "Что нового одной строкой"
git add -A && git commit -m "1.0.2" && git push
```
`make-package.sh` соберёт пакет и перепишет `manifest.txt`. Плата увидит версию при нажатии «Проверить».
