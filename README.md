# DigiNeo-updates

Каталог онлайн-обновлений для сетевого стримера **DigiNeo**. Плата читает `manifest.txt`,
скачивает указанный пакет, проверяет SHA-256 и ставит файлы без перепрошивки
(меню → Усилитель → Обновление).

## Формат
- `manifest.txt` — последняя версия: `version`, `file`, `sha256`, `size`, `notes`.
- `packages/digineo-<версия>.tar.gz` — пакет: `VERSION`, `files/` (дерево относительно `/`), необязательный `post.sh`.
- Разрешены только каталоги `var/www`, `opt`, `etc`, `usr/local`, `lib/systemd/system`.
  Если `post.sh` завершится с ошибкой — файлы автоматически возвращаются.

## Выпуск новой версии
Плата ставит **только последнюю** версию из `manifest.txt`, поэтому пакет должен быть накопительным
(содержать всё из предыдущих), а пользовательские настройки — класть в `opt/digineo/defaults` и копировать в `post.sh`, только если их нет.

```
mkdir -p src/files/var/www            # положить изменённые файлы по их путям на плате
bash tools/make-package.sh 1.0.2 src "Что нового одной строкой"
git add -A && git commit -m "1.0.2" && git push
```
`make-package.sh` соберёт пакет и перепишет `manifest.txt`. Плата увидит версию при нажатии «Проверить».

| 1.0.1 | Avahi ждёт подключения к сети: `digineo.local` находится после перезагрузки с Wi-Fi |
| 1.0.2 | Яндекс Музыка в меню усилителя: SOURCE → YANDEX MUSIC (волна, «Мне нравится», плейлисты, «Для вас»); нужна прошивка усилителя 1.8 |
| 1.0.3 | Обработка звука CamillaDSP: страница в меню, конфигурации (без коррекции, комната, кроссовер), редактор фильтров на порту 5000 |
| 1.0.4 | Улучшения DigiFox: pfctl как в DigiFox (трек и позиция через track.php — кириллица на экране усилителя; IP; веб-радио APlayer и Яндекс Музыка в меню усилителя; кнопки плеера с пульта; будильник и таймер сна; USB→I2S с усилителя; журнал событий усилителя), названия треков Qobuz Connect и AirPlay, страница «Радиостанции», прошивка усилителя 1.14 (SSD1322) и её обновление из меню (`digifox-ampflash`, ставит `stm32flash`), стрелочные индикаторы, новый `uac2_router` (DoP, `@HUSH`). Roon: название, обложка, позиция и кнопки пульта — расширение Roon `digineo-roon` (pyroon, вложен в `/opt/digineo/py`; включить «DigiNeo» в Roon → Настройки → Расширения; зона — `/etc/digineo/roon_zone`); нативный Qobuz Connect: кнопки пульта (`libassert_hook.so` с `qbz_ctl`, собирается в Actions — `tools/qobuz-hook`) |

Без go-librespot остаётся raspotify |
| 1.0.7 | **Накопительное.** Официальный **Spotify Soloist** (как на DigiFox): ключ вводится один раз в вебе — Усилитель → Spotify Soloist (developer.spotify.com → Soloist API Key, нужен Premium). Soloist нельзя распространять, поэтому плата скачивает его сама; он требует glibc 2.38+, а в Debian 11 — 2.31, поэтому плата берёт свежую glibc из Debian 13 (с проверкой SHA-256, в систему не ставится) и собирает шим `libpulse` (звук Soloist прямо в ALSA, MIT, [foonerd/alsa_soloist_connect](https://github.com/foonerd/alsa_soloist_connect)). Название, обложка, позиция и кнопки пульта работают. Без ключа — go-librespot. Исправлен запуск go-librespot (`$HOME`). Журнал: `/var/log/digineo-soloist.log` |
